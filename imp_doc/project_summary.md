Project Summary: Hierarchical Syllabus Checklist & Progress TrackerThe Hierarchical Syllabus Checklist & Progress Tracker is a production-grade, local-first academic planning and curriculum tracking system. It transforms unstructured multi-year university syllabi (.pdf, .docx, .doc, .txt) and live academic portal URLs into a verifiable, 5-tier nested checklist with cascading tri-state progress tracking, exam deadline pacing, study notes, resource bookmarks, and multi-format exports.   Canonical 5-Tier Academic Taxonomy: Enforces strict nesting below the Document Root:$$\text{Document Root} \longrightarrow \text{Academic Year (Tier 1)} \longrightarrow \text{Semester (Tier 2)} \longrightarrow \text{Subject / Course (Tier 3)} \longrightarrow \text{Module / Unit (Tier 4)} \longrightarrow \text{Subtopic Leaf (Tier 5)}$$   Zero-Hallucination Grounding & Multi-Format Ingestion: Combines fast-path digital parsing (pypdf, python-docx, headless LibreOffice for .doc, and an SSRF-hardened web portal scraper) with structured LLM extraction (Instructor + Pydantic) hot-switchable between local Ollama (llama3.1:8b / qwen2.5:7b / Qwen3-8B) and cloud OpenAI-compatible endpoints. Every extracted leaf retains verbatim source excerpts (source_text) and physical page/URL provenance.   Leaf-Only SQLite Persistence & Tri-State Cascades: SQLite runs in WAL mode with enforced foreign-key cascades, storing completion states strictly for Tier-5 leaf subtopics. Parent states (Checked ☑, Indeterminate ◐, Unchecked ☐) and completion percentages are calculated dynamically bottom-up across enrolled courses.   Academic Workflow Suite:Elective Onboarding & Historical Preservation: Modal checklist allowing students to filter enrolled electives before tree generation while preserving historical progress if courses are toggled.   Contextual Lab & Contact-Hour Metadata: Auto-detects lab courses (collapsed by default) and displays module contact hours as informational badges isolated from completion math.   Study Pacing & Deadlines (Option-A): Target exam date assignment per Semester/Subject with proportional contact-hour velocity calculations (topics/wk, hrs/wk) and status indicators.   Student Utilities & Exports (Option-B): Per-topic Markdown notes drawer with debounced auto-save, lecture/YouTube resource bookmarking, and exports to Markdown/Notion, Schema 2.1 JSON backups, and printable HTML/PDF reports.   Web Portal Scraper (Option-C): Dual-tab ingestion supporting direct university URLs with DNS-rebinding/SSRF protection and embedded PDF discovery.
